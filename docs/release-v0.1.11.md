鲸鱼娘 v0.1.11

新增“联网搜索”开关，默认关闭。开启后使用 Bing 公开 RSS 搜索，将最多 5 条网页摘要交给模型，回复下方显示来源、摘要和可打开的链接。可以单独填写搜索词；留空使用本条消息（最多 500 字），搜索词在本轮完成后清空。搜索失败或没有结果会明确提示，不伪装成成功。当前不抓取网页全文，也不执行网页中的指令或操作。

搜索服务只收到搜索词，不收到问卷、记忆库或模型 API 密钥；搜索摘要会随模型上下文发送到你配置的模型服务。可在发送前预览搜索词。Bing 公开 RSS 并非有服务保障的正式搜索 API，可能受网络、地区或服务调整影响。

修复第三方接口返回了思考内容却无法显示的问题：兼容 reasoning_content、reasoning 和 reasoning_details 中的文本，避免重复显示同一内容。思考与回复分开，支持流式显示并随本机聊天保存；不进入后续上下文、记忆整理或人格成长。只有推理 token、没有正文时准确说明。旧消息中未保存的思考正文无法补回。

提供 Intel Mac、Apple Silicon Mac、Windows x64。Mac 使用临时签名，Windows 未签名。
