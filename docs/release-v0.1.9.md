鲸鱼娘 v0.1.9

新增“关于鲸鱼娘”：它会根据已确认记忆、已审核的用户画像和明确反馈，逐渐形成适合你的聊天风格。六项表达习惯可手动选择、限制自动范围并锁定。每次最多自动微调两项、每项一级；较大变化、性格特点、称呼、关系表达和共同习惯先由你审核，可编辑或否定。

稳定底色为温柔、好奇、坦率，有独立判断并清楚自己是 AI，不编造共同经历。变化列出依据，支持暂停、删除反馈和历史回退；回退保留当前锁定，撤销依据会清理相关衍生记录。

成长与用户画像共用空闲总结任务，不在每句话后追加请求。发送范围可预览，用量归入“画像与成长”并计入今日和累计 token。数据留在本机，生成时向你配置的 API 发送必要输入；实际适应效果仍取决于模型和长期反馈。
