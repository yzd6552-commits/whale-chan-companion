鲸鱼娘 v0.1.8

新增“它如何理解我”：从已确认问卷和记忆形成初步理解，后台随新信息更新。明确自述与暂时推测分开，每条可查看依据、修改或否定；审核后才用于聊天。支持历史变化、删除判断和暂停自动整理。依据被修改或删除后，关联判断不再用于聊天。

首次空闲 2 分钟后整理，之后累计 5 条新增或更新的已确认记忆再更新，聊天优先。可选的后续问题也先审核，并限制询问频率。额外 API 消耗单列“画像总结”，计入今日及累计 token。

问卷提供初步了解，之后通过聊天逐步修正；你始终可以纠正它对你的理解。数据保存在本机；总结仅向你配置的 API 发送已确认记忆及已审核画像，可查看发送范围。

Intel Mac、Apple Silicon Mac、Windows x64。Mac 临时签名，Windows 未签名。
